# ごはんノート

個人用の食事管理・献立・買い物Webアプリ。要件定義書 v1.1 に基づく実装。

## セットアップ

初回セットアップは **`SETUP_GUIDE.md`** を参照してください（Supabase・Anthropic APIキーの取得からVercelへのデプロイまで手順化しています）。

## 技術スタック

- フロントエンド: Next.js (App Router) + TypeScript + Tailwind CSS v4
- DB / 認証 / ストレージ: Supabase (PostgreSQL, Auth, Storage)
- AI: Anthropic API (Claude Haiku 4.5) — レシピのカロリー・栄養推定
- ホスティング: Vercel (Hobby)

## ディレクトリ構成

```
src/
  app/
    page.tsx                ホーム画面
    login/                  ログイン・新規登録
    recipes/                レシピ一覧・詳細・新規登録
    calendar/                カレンダー(予定・実績・料理したくない日)
    shopping/                買い物リスト
    api/estimate-nutrition/  AIカロリー推定API
    inventory/                在庫管理(一覧・登録・編集・カテゴリ管理・場所管理・端末設定)
  components/                共通UIコンポーネント(アイコン、ナビ等)
  lib/
    supabase/                 Supabaseクライアント・型定義
    date.ts                   日付ユーティリティ
  proxy.ts                    認証セッション管理(旧middleware)
supabase/
  schema.sql                  テーブル定義(DDL)
  policies.sql                 Row Level Security ポリシー
```

## 実装済み機能(Phase 1〜2の範囲)

- ユーザー登録・ログイン(ユーザー名+パスワード方式)
- レシピ管理(登録・編集・詳細表示・お気に入り・削除・簡単メニュータグ・材料のグループ分け)
- レシピ登録時・編集時のAIカロリー推定(編集時は材料変更時のみ自動再計算、手動再計算ボタンあり)
- カレンダー(月表示、前月/翌月ナビゲーション、**1つの食事枠に複数料理を登録可能**、レシピ/外食/自由入力の組み合わせ、料理したくない日設定)
- 実績記録(写真+一言コメント)、最終調理日・調理回数の自動更新
- 買い物リスト(手動追加、チェック、購入履歴、よく買うもの、日付+食事枠を指定した献立からの自動集計、対象献立のプレビュー確認&個別除外)
- ホーム画面(今日の予定・カロリー概算・買い物件数)
- レスポンシブ対応(スマホ:下部タブ、PC/タブレット:左サイドバー)
- 主要な操作(チェック切り替え・お気に入り・料理したくない日設定)は楽観的UI更新で即座に反映
- 在庫管理(食材・日用品のストック管理)。パントリー等に常設したタブレットでカードをタップして在庫を減らす運用を想定。場所別の表示切り替え、カテゴリ順の自動並び替え、最低在庫数を下回ったら買い物リストへ自動追加(手動追加ボタンもあり)、カテゴリ・場所の追加・編集・削除。詳細は「在庫管理」節を参照

## 在庫管理

パントリーやクローゼットなどに常設タブレットを置き、荷物を取り出したらカードをタップして−1するだけ、という使い方を想定した在庫管理機能です。買い物リストと同じSupabaseプロジェクト内で動作するため、連携のための特別な設定は不要です。

- 在庫一覧(`/inventory`): カードをタップするだけで在庫数を−1(補充は右上の小さな+ボタン)。カテゴリの並び順でセクション分けして自動表示するため、並び替え操作は不要。タップ直後は「元に戻す」が5秒間表示され、誤タップを取り消せる
- 場所(`inventory_locations`)によるフィルタ: 「場所を管理」(`/inventory/locations`)でパントリー・クローゼットなどの場所を登録できる。各端末(タブレット)には「管理」→「この端末の表示場所」(`/inventory/manage/location`)で1つだけ場所を割り当て、その端末にはその場所の商品だけを表示する。この設定は各端末のブラウザの`localStorage`だけに保存され、サーバーには送らないため、複数台のタブレットを同時に使っても設定が競合しない
- 管理メニュー(`/inventory/manage`): 商品の追加・カテゴリ管理・場所管理・この端末の表示場所設定への入口をまとめたハブ画面
- 商品の登録・編集(`/inventory/new`, `/inventory/[id]/edit`): 商品名・カテゴリ・場所・単位・現在の在庫数・最低在庫数・写真(任意、カメラ撮影のみ。バーコード読み取りや外部商品データベースとの連携は行わない)。新規登録時は、その端末の表示場所をデフォルトで選択する
- 最低在庫数を下回ると、自動的に買い物リスト(`shopping_items`、`source='auto_from_inventory'`)に追加される。同じ商品は重複して追加されない(`inventory_items.added_to_shopping_list`で管理)。+ボタンで補充すると、このフラグはリセットされ、次に在庫が減ったときに再度追加されるようになる
- カードから手動で「買い物リストに追加」することも可能
- カテゴリ管理(`/inventory/categories`): 買い物リストの手動追加時に選ぶカテゴリ(`shopping_categories`)と共通。ここで追加・編集・削除したカテゴリは買い物リスト側にもそのまま反映される
- 常設タブレット向けの工夫: 画面が自動で消えないようにするWake Lock、他端末での変更を取り込むための3分ごとの定期更新、毎日深夜4時の自動リロードを組み込んでおり、電源・画面をオンにしたまま常設しても問題なく動作する
